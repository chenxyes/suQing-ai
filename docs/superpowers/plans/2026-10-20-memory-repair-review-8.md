## 已修复的行为

原本三档长度设置分别被转成每条 15/20/25 字，随后又被全局“每条不超过 15 字”覆盖；“长聊”也被要求两三句就停。现在简短通常 1–2 句、适中通常 3–4 句、长聊在话题需要时可展开至 5 句以上；当轮明确需求及安全回应优先。不承诺模型每次严格满足句数，不为凑数灌水。非法设置包括对象继承属性名统一回退到适中。

删除“偶尔记岔更像真人”、固定次数反对/调侃、固定问句比例和重复台词。提示改为围绕当前话题表达观点、使用有证据的共同经历，不编造角色刚完成的活动。保留现有心情、关系阶段和生活状态；主动开场明确采用简短、单话题的例外。忙碌、低能量等状态仍可缩短回应。

发送端还存在独立的数据丢失问题：超过 20 字且没有半角 `||` 时先按句末拆分，再只取前四句，后续正文直接消失。现移除按字数和句末自动拆分，只识别 `||`、`｜｜` 和换行；仍最多发送四条，超过时将第四段及后续内容以换行合并。完整长段落和带问号的 URL 不再被这个阶段额外拆开。原有标点/空白/颜文字清理、发送去重及失败处理保持原实现。

记忆主体分组、unknown/摘要来源限制、synthetic 隔离、安全模式及危险请求边界、照片真实性边界均保留。独立审查和回归未发现这些边界因本轮精简而失效。

## 记忆插件与迁移结论

当前先保留修复后的 SQLite 作为事实、证据、状态与撤销记录的权威来源。原先串线、召回过滤和本轮表达约束都有具体原因，不能简单归因于 DeepSeek 或未选某个记忆插件。

外部系统首选试验 **Mem0 OSS**：适合通用个性化与检索接入，先作为已验证事实的候选索引。只有复杂关系与历史时间查询在评测中明显受益时再考虑 **Graphiti**。Zep 托管有持续服务依赖；Letta 涉及 agent 框架重构，不适合当前局部替换。项目尚无这些适配器，本文没有宣称它们可直接安装替换。

第 7 项 v2 导出提供迁移档案，保留主体、证据、状态、来源、向量身份与 ID 映射依据；外部适配器仍需开发。先隔离导入、重新核验/建向量，再影子比较召回，最后才考虑切换；旧 unknown 和撤销事实不能借迁移变可信。详细理由、官方核验来源及删除/回退边界见 [记忆系统选型与迁移建议](2026-10-20-memory-system-options.md)。
