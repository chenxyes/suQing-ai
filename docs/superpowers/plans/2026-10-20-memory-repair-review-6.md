# 第 6 项本地修复审阅：作品类别、进度与表达

第 5 项已接受并提交为 `894e2f9 fix(safety): verify speaker evidence before minor classification`。本项候选位于 `codex/memory-repair`，已于 2026-10-20 获用户接受并授权本地提交；未推送、未部署。

## 问题与修复

过去，游戏、剧集或动画候选验证失败后会统一变成 book，未验证的题材被写入 title，普通活动进度也不再推进。主动消息又独立套用“那本……”和“刚看完一章”，可能让游戏变成书。另一个提示词要求把当前档案外的作品一律说成“看完了”，会引入无依据的经历。

本项统一了降级、日程、对话、主动消息、照片资格和归档中的类别表达：

| 场景 | 修复后 |
| --- | --- |
| 游戏或剧集无法验证 | 保留最近有效候选的类别，使用“游戏”“剧集”等占位，不保留未经证实的名字或制作方 |
| 没有搜索服务、服务失败、到达验证配额 | 返回可区分的降级原因，不伪装成验证成功 |
| 未验证活动继续进行 | 根据在档阶段更新“接着玩一会儿”“还在追剧”等普通活动文案；不编造章节、关卡、集数或通关 |
| 主动分享游戏或剧集 | 使用对应类别的表达，不再套书籍示例；保留素材冷却和使用记账 |
| 未验证活动参与照片选择 | 不占作品照片槽，不覆盖原有场景；已验证作品和手工继续使用原有照片流程 |
| 未验证活动到期归档 | 只记录这阵子的活动告一段落或暂时放下，不宣称完成具体作品 |
| 提起当前档案外的旧作品 | 允许说明进度未确认，不因档案缺席而断言看完 |

独立审查进一步发现并修复三个问题：类别末尾空格绕过验证、未知类别被当作手工免验、已验证游戏归档仍误用“看完”。现在候选类别统一去空格和大小写，检查白名单和字段类型；只有明确的 craft 可以免验，未知类别降级并丢弃候选名。游戏归档使用“玩过”“暂时放下”等文案，不凭生命周期到期宣称通关。

## 使用范围

- 普通活动进度是由在档时间驱动的角色生活模拟，不表示项目实际操作手机、运行游戏或观看视频。真实作品的存在性验证仍依赖搜索服务。
- 本次没有验证真实模型的自然度、服从率或线上搜索配置。修复了可复现的类别和提示词问题，不把离线通过当作“已经更像真人”的实测结论。
- 服务器旧记录中误存成 book 的条目不会自动恢复原类别，因为原始类别可能已经丢失。未迁移或删除旧作品和历史记忆。
- 降级原因通过刷新结果返回，未新增数据库字段或管理界面。没有任何有效候选时仍采用普通阅读占位；它不代表某本真实作品已被验证。
- 正常生命周期、真实作品验证缓存、角色自身生活设定和现有安全模式保留。本项没有引入新的记忆插件。

生产修改位于 `src/current_works.mjs` 和 `src/proactive.mjs`；其余为相关测试、CI 与审阅记录。
