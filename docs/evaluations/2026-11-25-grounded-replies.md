# 狗头军师 V1 回复与记忆验收（2026-11-25）

在真实 `deepseek-chat` 上，四组合成对话共 15 轮，全部返回聊天文字。另用相同的 12 份固定草稿分别测试按需审查和全量审查。两种模式都纠正了 8 个坏例，原样保留了 3 个正例。最后一个样本是无事实的短确认，按需模式跳过审查，全量模式调用审查后保留原话。逐条输入、固定草稿、最终文字、调用及耗时见[按需报告](2026-11-25-grounded-adaptive.json)和[全量报告](2026-11-25-grounded-all.json)。

## 遇到的问题和修复

| 问题 | 原因与处理 | 实际结果或验证范围 |
|---|---|---|
| 说“味道不错”却被当作确认是买的，还编造自己吃过饭 | 助手的选择题、角色背景和当前回答混在一起。生成、审查都能看到说话人和原句，审查后的个人线下经历还须有依据。 | 故障草稿实际改成“味道不错就好。”；原话明确是自己煮时，正确回应保留。 |
| 给出八点半至九点，却被催着八点半到 | 初版审查只删“别拖”，仍缩窄时间。对仅陈述空闲时段的输入，引用时间就须保留范围，也可以只确认。 | 固定草稿和多轮对话都回“好，你有空的时候聊。”；明确请她选时间有单独正例。 |
| 说想暂停、随后回“好的”，仍被追问 | 模型修订时会换个问法继续。程序在无行动计划的确认轮检查上一条实质性来信是否已要求停止。 | 两模式均回“好。”。明确求建议时则实际给出如何与领导沟通的做法。 |
| 拿到驾照后被补写焦虑或先前失败；争执后被“只是随口一说”搪塞 | 自由独白、方法卡示例曾被当作当事人的经历。现在只采用已校验行动与对话证据，审查行动是否在文字中兑现。 | 祝贺保留，虚构的失败史删除；争执时就此前说过的话道歉。 |
| 打招呼时被说成昨晚发过消息；已吃完 KFC 又被追问 | V1 回复区分当前来信、事件日期、解决状态及角色自己的历史发言。简单早安不需借往事接话。 | 两份错误回复均改成“早呀。”。这里测试的是聊天回复和固定草稿。系统定时早安另由 [PR #6](https://github.com/chenxyes/suQing-ai/pull/6) 处理，系统主动回访的事件核销在 [PR #8](https://github.com/chenxyes/suQing-ai/pull/8)。两项都另待发布。 |
| 配好向量后仍取不到已压缩的原句 | 旧检索为节省篇幅会隐藏压缩源，V1 又会舍弃缺少原句的摘要。V1 先在允许召回的来源中选可用原句，再用关键词、向量排名；验证依赖的范围独立于返回条数。 | 临时 SQLite 复验压缩后只取一条仍能得到原句，禁用其依赖后该事实消失。旧库中从未保存证据的记忆不会凭向量分数补成事实。 |
| 审查服务失败，或修订带出内部字段及新媒体动作 | 审查协议校验最终文字，失败走降级。角色自述与长期事件文本分别检查来源和隐私。 | HTTP + SQLite 检查最终文字、执行记录、预约、降级、probe 零写入；微信另有部分送达和取消竞态回归。 |

## 语气与开销

平时的表达原则集中在 [SOUL.md](../../config/SOUL.md)，角色、个人偏好和当前行动分开提供。SOUL 每次生成仍占输入上下文。向量检索负责寻找旧资料，审查模型负责判断当轮草稿是否符合资料和表达边界。真实模型在“拿到驾照”的固定样本中仍加了“今天可以好好放松一下了”，求助草稿有时在给出实质建议后又问了一句。当前验收覆盖指定事实错误、施压和停止场景；个别回复仍比用户示例啰嗦。

| 15 轮真实回放 | 调用次数 | 输入 token | 输出 token |
|---|---:|---:|---:|
| 行动与冲突判断 | 13 | 5,522 | 494 |
| 生成回复 | 15 | 13,680 | 191 |
| 输出审查 | 15 | 19,475 | 226 |
| 总计 | 43 | 38,677 | 911 |

这批多轮样本全部触发审查，0 次降级。端到端均值 3.00 秒，P95 为 4.10 秒；审查调用平均耗时 0.95 秒。上一版相同场景启用 V1 的 15 轮共记录 56,071 个输入 token，平均 2.48 秒。两次测量日期不同，旧版账本还漏记部分直接调用，不能据此估算实际费用差额。详见[上一版回放](2026-11-24-behavior-v1.md)。

## 复验

四组对话分别覆盖受挫、庆祝、争执、日常聊天。在隔离 SQLite 和合成成年角色中运行，复用聊天 provider 设置，结束后清理临时目录。多轮场景关闭长期记忆抽取；向量与压缩修复另外用 SQLite 测试。首轮虽然所有坏例都被标为修订，逐句检查仍发现“八点半左右，我等你”和“昨晚的鸡翅”。第二轮还残留“我晚上随便吃了点”，最终轮才消除这两类错误。上述结果限于这批样本及本次模型。

```sh
npm run check:behavior
node scripts/memory_retrieval_check.mjs
node scripts/behavior_model_eval.mjs --variant on --suite both --review-mode adaptive --output /tmp/grounded-adaptive.json
node scripts/behavior_model_eval.mjs --variant on --suite fixed --review-mode all --output /tmp/grounded-all.json
```
